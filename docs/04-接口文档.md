# 04 · 接口文档（REST API）

- Base URL：`https://{域名}/api`（本地开发 `http://127.0.0.1:8000/api`）
- 交互格式：JSON（`Content-Type: application/json`；导入接口为 `multipart/form-data`）
- 在线调试：FastAPI 自动文档 `GET /docs`（Swagger）
- 计算口径见 [03-核心业务规则](./03-核心业务规则.md)，字段落库见 [02-数据库设计](./02-数据库设计.md)

## 0. 通用约定

### 0.1 鉴权

除注册/登录/微信登录外，所有接口要求请求头：

```
Authorization: Bearer <access_token>
```

- access_token 有效期 2 小时；refresh_token 30 天
- 管理员接口前缀 `/api/admin/*`，要求 `role ∈ {admin, super_admin}`

### 0.2 统一响应包络

```json
{ "code": 0, "msg": "ok", "data": { } }
```

错误：

```json
{ "code": 2001, "msg": "用户名或密码错误", "data": null }
```

### 0.3 分页

请求：`?page=1&page_size=20`（默认 page_size=20，最大 100）
响应：

```json
{ "code": 0, "msg": "ok", "data": { "items": [ ], "total": 86, "page": 1, "page_size": 20 } }
```

### 0.4 空数据约定

列表无数据返回**空数组 `[]`**（不返回 null）；统计无数据时金额字段返回 `0`。

### 0.5 错误码表

| code | HTTP | 含义 |
|---|---|---|
| 0 | 200 | 成功 |
| 1001 | 422 | 参数校验失败（字段/类型/枚举非法），data 返回字段级错误 |
| 1002 | 401 | 未登录 / token 缺失 |
| 1003 | 401 | token 过期或无效（前端应 refresh 后重试，失败跳登录） |
| 1004 | 403 | 无权限（普通用户访问 admin 接口） |
| 1005 | 404 | 资源不存在或不属于当前用户（不区分，防探测） |
| 2001 | 401 | 用户名或密码错误 |
| 2002 | 409 | 用户名/邮箱已存在 |
| 3001 | 409 | 该标的持仓已存在（同 market+code） |
| 4001 | 400 | 卖出后持仓数量为负，拒绝 |
| 4002 | 400 | 股权登记日无符合条件的持仓股数，无法生成分红 |
| 5001 | 409 | 预案重复（同 market+code+ex_date 已发布） |
| 9000 | 500 | 服务器内部错误 |

### 0.6 枚举字典

- `market`：`a_share` A股 / `us_stock` 美股 / `hk_stock` 港股 / `fund` 基金 / `bond` 债券
- `currency`：`CNY` / `USD` / `HKD`
- `freq`：`monthly` 月派 / `quarterly` 季派 / `semi_annual` 半年派 / `annual` 年派 / `irregular` 不定期 / `unknown`
- `direction`：`buy` 买入 / `sell` 卖出 / `bonus_share` 送转
- `div_status`：`pending` 待到账 / `confirmed` 已到账
- `sch_status`：`pending` 待审核 / `published` 已发布 / `rejected` 已驳回

# 一、认证模块 `/api/auth`

## 1.1 注册

`POST /api/auth/register`（免鉴权）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| username | string | 是 | 登录名，4–32 位，唯一 |
| email | string | 否 | 邮箱格式校验 |
| password | string | 是 | ≥8 位，bcrypt 存储 |
| nickname | string | 否 | 默认取 username |

响应 data：

```json
{ "user": { "id": 1024, "username": "demo@xi.com", "nickname": "demo@xi.com", "role": "user" },
  "access_token": "eyJ...", "refresh_token": "eyJ...", "token_type": "bearer" }
```

错误：2002 用户名已存在；1001 密码过短。

## 1.2 登录

`POST /api/auth/login`（免鉴权）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| account | string | 是 | username 或 email |
| password | string | 是 | |

响应：同 1.1（额外更新 last_login_at）。错误：2001 账号或密码错误；账号被封禁返回 1004 + msg「账号已封禁」。

## 1.3 刷新 token

`POST /api/auth/refresh`（免鉴权）

| 字段 | 类型 | 必填 |
|---|---|---|
| refresh_token | string | 是 |

响应：`{ "access_token": "...", "refresh_token": "..." }`（refresh 轮换）。错误：1003。

## 1.4 当前用户

`GET /api/auth/me` → data：

```json
{ "id": 1024, "username": "demo@xi.com", "email": "demo@xi.com", "nickname": "demo@xi.com",
  "avatar": null, "role": "user", "base_currency": "CNY", "has_wx": false, "created_at": "2024-03-12 10:01:33" }
```

## 1.5 微信小程序登录

`POST /api/auth/wx-login`（免鉴权）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| code | string | 是 | wx.login() 返回的临时 code |
| nickname / avatar | string | 否 | 小程序 getUserProfile 资料 |

服务端流程：code → 微信 code2session 换 openid → 已绑定则登录；未绑定则创建用户（随机密码、username=wx_{openid前8位}）→ 返回 JWT。
响应同 1.1，data 额外 `{ "is_new_user": true }`。错误：1001 code 无效。

## 1.6 退出

`POST /api/auth/logout` → `{}`（V1 前端清 token；V2 加 refresh 黑名单）

# 二、持仓模块 `/api/holdings`

## 2.1 持仓列表（含计算字段）

`GET /api/holdings`

Query：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| market | enum | 否 | 市场筛选 |
| keyword | string | 否 | 代码/名称模糊搜索 |
| freq | enum | 否 | 派息频率 |

响应 data.items[]：

```json
{
  "id": 11, "market": "a_share", "code": "600519", "name": "贵州茅台",
  "currency": "CNY", "account": "华泰证券", "freq": "annual", "note": "",
  "shares_now": 100,            // 计算：当前净持仓
  "avg_cost": 1676.0000,        // 计算：加权平均成本（4位小数）
  "cost_total": 167600.00,      // 计算：总投入
  "lot_count": 2,               // 计算：批次笔数
  "year_dividend": 2580.00,     // 本年度税前（原币）
  "total_dividend": 11923.16,   // 累计税后（原币）
  "yoc_ttm": 0.0360,            // 计算：成本股息率（小数，前端×100%）
  "created_at": "2024-03-15 09:20:00"
}
```

## 2.2 新增持仓（同时建首笔批次）

`POST /api/holdings`

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| market | enum | 是 | |
| code | string | 是 | |
| name | string | 是 | |
| currency | enum | 是 | |
| account | string | 否 | 券商/账户 |
| freq | enum | 否 | 默认 unknown，后台数据可自动回填 |
| note | string | 否 | |
| first_lot | object | 否 | 首笔买入批次，结构同 3.2 |
| first_lot.trade_date | string(YYYY-MM-DD) | 条件必填 | |
| first_lot.shares | number | 条件必填 | >0 |
| first_lot.price | number | 条件必填 | ≥0 |
| first_lot.fee | number | 否 | 默认 0 |
| first_lot.note | string | 否 | |

响应：创建的 holding（含计算字段）。错误：3001 重复持仓；1001。

## 2.3 持仓详情

`GET /api/holdings/{id}` → holding 全字段 + `{ "shares_now", "avg_cost", "cost_total", "lot_count", "year_dividend", "total_dividend", "yoc_ttm" }`。错误：1005。

## 2.4 编辑持仓

`PATCH /api/holdings/{id}`：可改 name/account/freq/note/currency（改币种需用户确认，历史分红币种不动）。错误：1005。

## 2.5 删除持仓

`DELETE /api/holdings/{id}`：级联删除 lots/dividends/allocations（软删 V2 加 deleted_at）。错误：1005。

# 三、批次模块 `/api/holdings/{id}/lots`、`/api/lots`

## 3.1 批次列表

`GET /api/holdings/{id}/lots` → data.items[]：

```json
{ "id": 101, "trade_date": "2022-03-15", "direction": "buy", "shares": 60,
  "price": 1580.0000, "fee": 15.00, "amount": 94800.00,   // amount = shares×price+fee(buy)
  "lot_dividend": 9295.96,                                 // 该批次累计税后分红
  "note": "首次建仓" }
```

## 3.2 新增批次（加仓/减仓/送转）

`POST /api/holdings/{id}/lots`

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| trade_date | date | 是 | |
| direction | enum | 是 | buy/sell/bonus_share |
| shares | number | 是 | >0 |
| price | number | 条件必填 | buy 必填>0；sell 必填；bonus_share=0 |
| fee | number | 否 | 默认 0 |
| note | string | 否 | |

服务端：校验卖出不超持仓（否则 4001）→ 落库 → **触发相关分红重算**（03 文档 §2.4）。
响应：新批次 + 重算后的持仓汇总。

## 3.3 编辑/删除批次

`PATCH /api/lots/{id}`、`DELETE /api/lots/{id}`：同样触发重算；删除后 allocations 保留快照（lot_id 置空）。错误：1005 / 4001。

# 四、分红模块 `/api/dividends`

## 4.1 分红记录列表

`GET /api/dividends`

Query：`year`(2026)、`market`、`holding_id`、`status`(pending/confirmed)、`page`、`page_size`

data.items[]：

```json
{ "id": 501, "holding_id": 11, "holding_name": "贵州茅台", "code": "600519",
  "market": "a_share", "ex_date": "2026-08-06", "record_date": "2026-08-05",
  "pay_date": "2026-08-25", "dps": 25.8000, "eligible_shares": 100,
  "gross_amount": 2580.00, "tax": 0.00, "net_amount": 2580.00,
  "currency": "CNY", "net_cny": 2580.00,          // 派息日汇率折算
  "div_type": "cash", "source": "manual", "status": "confirmed",
  "allocations": [                                // expand=allocations 时返回
    { "lot_id": 101, "lot_date": "2022-03-15", "shares": 60, "gross": 1548.00, "tax": 0, "net": 1548.00 },
    { "lot_id": 102, "lot_date": "2023-09-20", "shares": 40, "gross": 1032.00, "tax": 0, "net": 1032.00 }
  ] }
```

## 4.2 手动记录分红（自动跑归属算法）

`POST /api/dividends`

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| holding_id | int | 是 | |
| ex_date | date | 是 | |
| record_date | date | 否 | 缺省：美股=ex_date；A股=ex_date 前一自然日（提示校对） |
| pay_date | date | 是 | |
| dps | number | 是 | 每股分红（税前） |
| tax | number | 否 | 缺省自动估算（§3 规则）；传了则 tax_overridden=1 |
| div_type | enum | 否 | 默认 cash |
| status | enum | 否 | 默认 confirmed；预告录入用 pending |
| note | string | 否 | |

服务端：归属算法（03 §2）→ 写 dividends + allocations → 返回完整对象。
错误：4002 无符合条件股数；1005 持仓不存在。

## 4.3 分红详情

`GET /api/dividends/{id}`：含 allocations 全量。

## 4.4 编辑/删除分红

`PATCH /api/dividends/{id}`：可改日期、dps、tax（改税标记 tax_overridden=1）、status、note；改 dps/日期触发重算。
`DELETE /api/dividends/{id}`：级联删 allocations。

## 4.5 确认到账

`POST /api/dividends/{id}/confirm`：pending → confirmed，可携带实际到账金额：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| actual_net | number | 否 | 实际到账（与估算不符时覆盖 net_amount，tax 倒挤） |

## 4.6 预告自动匹配

`POST /api/dividends/auto-match`：扫描已发布 schedules，为当前用户持仓生成 pending 分红（幂等）。
响应：`{ "matched": 3, "created": [ {"schedule_id": 88, "holding_id": 11, "net_amount": 1260.0} ], "skipped": 1 }`。
服务端每日定时自动执行一次，此接口供用户手动触发。

# 五、分红预告（公共数据）`/api/schedules`

`GET /api/schedules/upcoming` → data：

{ "items": [

# 八、导入导出 `/api/import`、`/api/export`

## 8.1 导入持仓（多批次）

`POST /api/import/holdings`（multipart，字段 `file`，CSV）

模板列：`market,code,name,currency,account,trade_date,direction,shares,price,fee,note`
响应：

```json
{ "holdings_created": 3, "holdings_updated": 2, "lots_inserted": 11,
  "skipped": [ {"row": 8, "code": "600519", "reason": "trade_date 格式错误"} ] }
```

同 code 多行 → 归并 1 持仓 + N 批次；重复批次（同 code+date+shares+price）跳过。

## 8.2 导入分红

`POST /api/import/dividends`（CSV：`market,code,ex_date,record_date,pay_date,dps,tax,currency`）
响应：`{ "inserted": 14, "matched_holdings": 9, "skipped": [ {"row":3,"reason":"未找到持仓"} ] }`
匹配后自动跑归属算法。

## 8.3 导出

`GET /api/export?format=json|csv` → 文件流（`Content-Disposition: attachment`）。
json 为全量备份（含 holdings/lots/dividends/allocations/settings），可用于「换设备恢复」。
