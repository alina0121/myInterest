# 05 · 前端三端设计（uni-app 一套代码 → H5 / App / 微信小程序）

## 1. 技术栈

- **uni-app（Vue3 + TypeScript + Vite）** —— 一套代码编译三端
- 状态：Pinia（user/token、全局设置、列表缓存）
- UI 组件：uv-ui（或 uview-plus），三端兼容
- 图表：**uCharts 为全端默认**（canvas，小程序/App/H5 都能跑）；H5 可条件编译用 ECharts
- 请求：`uni.request` 自封装拦截器（对应 04 接口文档）
- 构建：HBuilderX 或 CLI（`npm run dev:h5 / build:h5 / build:app / build:mp-weixin`）

## 3. 请求封装（三端共用契约）

```
baseURL：
  H5        → '/api'（同源，Nginx/Caddy 反代）
  App/小程序 → 'https://api.你的域名.com/api'
请求头：Authorization: Bearer <token>（token 存 storage）
响应拦截：
  code=0      → return data
  code=1003   → 尝试 /auth/refresh 一次；仍失败 → 清 token 跳登录页
  code=1002   → 跳登录页
  code=1005   → toast「记录不存在或已被删除」
  其他        → toast msg
```

## 4. 页面 ↔ 接口映射（与原型 6+1 页对应）

| 页面 | 进入时机 | 调用接口 |
|---|---|---|
| 登录/注册 | 启动无 token | `POST /auth/login`、`/auth/register`；小程序 `POST /auth/wx-login` |
| 总览看板 | onShow | `/stats/summary`、`/stats/monthly-trend`、`/stats/by-market`、`/stats/forecast`、`/dividends?status=confirmed`（最近到账）、`/schedules/upcoming` |
| 持仓列表 | onShow | `GET /holdings`（含计算字段）；筛选 market/keyword |
| 持仓详情 | 点击行 | `GET /holdings/{id}`、`GET /holdings/{id}/lots`、`GET /holdings/{id}/stats`、`GET /dividends?holding_id=&expand=allocations` |
| 添加持仓/批次 | 弹窗 | `POST /holdings`（带 first_lot）/ `POST /holdings/{id}/lots`；批次删除 `DELETE /lots/{id}` |
| 分红记录列表 | onShow | `GET /dividends`（year/market/status 筛选 + 分页）；行展开取 allocations |
| 记录分红 | 弹窗 | `POST /dividends`（后端自动归属）；确认到账 `POST /dividends/{id}/confirm` |
| 分红日历 | onShow | `GET /calendar?year=&month=` |
| 统计分析 | onShow | `/stats/forecast`、`/stats/top-holdings`、`/stats/yield-ranking`、`/stats/by-market` |
| 设置 | - | `GET/PUT /settings`、`GET /rates`、`/import/holdings|dividends`、`GET /export` |
| 我的 | TabBar | `/auth/me`、`/feedback/me`、公告 `/announcements`、退出 `POST /auth/logout` |

## 5. 三端差异矩阵（条件编译 `#ifdef`）

| 维度 | H5(Web) | App | 微信小程序 |
|---|---|---|---|
| 布局 | ≥768px 侧边栏 + 栅格；窄屏自动切 TabBar | 顶部栏 + 底部 TabBar | 同 App |
| 单位 | rpx（750rpx=屏宽），设计稿 375pt | 同左 | 同左 |
| 登录 | 账号密码 | 账号密码；V2 指纹/面容 | `wx.login` 静默授权 + 昵称头像；账号密码兜底 |
| token 存储 | localStorage（uni 封装一致） | plus.storage | uni.storage（持久化，上限 10MB） |
| 图表 | uCharts（可选 ECharts） | uCharts | uCharts（**ECharts 需 lime-echart 插件且占体积，默认不用**） |
| 分红提醒 | 邮件/站内信（V2） | unipush 推送 | **订阅消息**（见 §6.4） |
| CSV 导入 | `<input type=file>` 直接选 | plus.io 文件选择/分享导入 | `wx.chooseMessageFile` 从聊天会话选文件；或提供「粘贴表格文本」 |
| 导出 | Blob 下载 | 保存到本地 + 系统分享 | 导出受文件系统限制：V1 提供「生成分红年报图片」分享；JSON 备份引导到 H5 |
| 安全区 | 不需要 | `safe-area-inset-bottom` | 同 App |
| 列表长分页 | 分页器 | `onReachBottom` 上拉加载 | 同 App |

## 6. 微信小程序专项（重点，决定能否过审上架）

### 6.1 前置条件
- 注册小程序账号、拿到 **AppID**；服务器域名 **必须 HTTPS + ICP 备案**
- 小程序后台「开发管理」配置 **request 合法域名**（API 域名）；开发期可在开发者工具勾选「不校验域名」
- 类目选择：工具 / 记账理财类（**不可出现荐股、交易引导、收益承诺等内容**，否则审核驳回；文案定位为「个人记账工具」）

### 6.2 登录流程
```
wx.login() → code
  → POST /api/auth/wx-login { code }
  → 后端 code2session 换 openid（appid+secret 存后端，不下发）
  → 返回 JWT；is_new_user=true 时引导补昵称
头像昵称：用小程序「头像昵称填写能力」（button open-type=chooseAvatar + input type=nickname）
```

### 6.3 包体与分包
- 主包只放：登录 + TabBar 五页；**主包 ≤ 2MB**
- 详情/统计/设置/导入全部放 `pages-sub/` 分包；整包 ≤ 20MB
- 图表库按需引入；uv-ui 按需组件

### 6.4 分红提醒（订阅消息）
- 小程序**不能随便推送**，用「一次性订阅消息」：用户在「设置」点开关 → `wx.requestSubscribeMessage` 授权（每次授权允许发 1 条，可引导一次授权多条累计）
- 模板：「分红到账提醒」（标的、金额、派息日）、「分红预告提醒」（登记日提醒）
- 后端：预案发布/到账日定时任务批量调微信 subscribeMessage API（需 access_token，服务端缓存）

### 6.5 数据缓存与秒开
- 总览统计：进页面先渲染 storage 缓存 → 拉接口静默刷新（stale-while-revalidate）
- storage 只存摘要（summary、最近列表），不存全量明细

### 6.6 审核注意清单
- 无用户 UGC 公开展示（反馈仅后台可见，不做社区）
- 隐私政策页 + 用户协议；首次启动弹隐私授权
- 不出现证券交易、开户、买卖建议；"分红"相关文案描述为「记录您自己的到账数据」

## 7. H5 与 App 发布

- **H5**：`build:h5` 产物 `dist/build/h5/` 交给 FastAPI 用 StaticFiles 托管（同域 /api），Caddy 提供 HTTPS
- **App**：HBuilderX 云打包（Android APK 直接分发；iOS 需 Apple 开发者账号 + TestFlight/上架）
- **小程序**：`build:mp-weixin` → 微信开发者工具打开 → 上传 → 提审
- 版本检查：App/H5 启动拉 `/api/announcements` 或版本接口提示更新（小程序由微信商店自动更新）

## 8. 移动端 TabBar 与页面适配（已在原型演示）

- TabBar 五项：总览 📊 / 持仓 📈 / 记分红 ➕ / 日历 📅 / 我的 👤（见 prototype.html 移动端预览）
