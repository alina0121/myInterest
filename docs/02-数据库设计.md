# 02 · 数据库设计

- 数据库：**SQLite 3**（WAL 模式），单文件 `data/xi.db`；表名小写下划线
- 金额约定：`NUMERIC` 类型（SQLite 内部按 REAL/INTEGER 亲和），**Python 端用 `Decimal` 计算，落库前四舍五入**（每股分红 4 位小数、金额 2 位小数）；展示层金额 2 位
- 时间：统一 ISO 字符串 `YYYY-MM-DD HH:MM:SS`（UTC+8），日期字段 `YYYY-MM-DD`
- 所有业务表含 `user_id`（除全局公共表：dividend_schedules / exchange_rates / tax_rules / announcements）
- 字段标注：【硬】需求硬性字段 【扩】为关联查询/隔离必需的扩展字段 【工】工程通用字段

## ER 关系总览

```
users 1 ──< holdings 1 ──< lots            （持仓 → N 笔买入/卖出批次）
users 1 ──< dividends 1 ──< dividend_allocations >── lots   （分红 → 批次级归属明细）
holdings 1 ──< dividends
dividend_schedules 1 ──< dividends          （分红记录可由「已发布预案」自动生成）
users 1 ──< feedback
users 1 ──1 user_settings
admins(users.role=admin) ──< admin_operation_logs
exchange_rates / tax_rules / announcements  （全局公共表，后台维护）
```

## 1. users 用户表

```sql
CREATE TABLE users (
  id              INTEGER PRIMARY KEY AUTOINCREMENT,
  username        TEXT NOT NULL UNIQUE,              -- 【硬】登录名（邮箱/自定义）
  email           TEXT UNIQUE,                       -- 【硬】邮箱（可空，微信用户可后绑）
  phone           TEXT,                              -- 【扩】手机号（小程序快捷登录）
  password_hash   TEXT NOT NULL,                     -- 【工】bcrypt；微信用户初始随机密码
  nickname        TEXT,                              -- 【硬】昵称
  avatar          TEXT,                              -- 【扩】头像 URL
  wx_openid       TEXT UNIQUE,                       -- 【扩】微信 openid（小程序登录）
  wx_unionid      TEXT,                              -- 【扩】微信 unionid（多端打通）
  role            TEXT NOT NULL DEFAULT 'user'
                  CHECK (role IN ('user','admin','super_admin')),  -- 【扩】角色
  status          TEXT NOT NULL DEFAULT 'active'
                  CHECK (status IN ('active','banned')),           -- 【扩】状态
  base_currency   TEXT NOT NULL DEFAULT 'CNY'
                  CHECK (base_currency IN ('CNY','USD','HKD')),    -- 【扩】统计折算本位币
  created_at      TEXT NOT NULL DEFAULT (datetime('now','localtime')),  -- 【工】
  last_login_at   TEXT                               -- 【工】最近登录时间
);
CREATE INDEX idx_users_openid ON users(wx_openid);
```

## 2. holdings 持仓表（一只标的一条）

```sql
CREATE TABLE holdings (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id     INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,  -- 【扩】隔离
  market      TEXT NOT NULL CHECK (market IN ('a_share','us_stock','hk_stock','fund','bond')),
  code        TEXT NOT NULL,        -- 【硬】证券代码：600519 / AAPL / 00700 / 005827
  name        TEXT NOT NULL,        -- 【硬】名称：贵州茅台
  currency    TEXT NOT NULL DEFAULT 'CNY' CHECK (currency IN ('CNY','USD','HKD')),
  account     TEXT,                 -- 【硬】所属账户/券商：华泰证券、富途牛牛
  freq        TEXT DEFAULT 'unknown'
              CHECK (freq IN ('monthly','quarterly','semi_annual','annual','irregular','unknown')),
                                    -- 【扩】派息频率（后台/爬虫回填，用于预测与节奏统计）
  note        TEXT,                 -- 【硬】备注
  created_at  TEXT NOT NULL DEFAULT (datetime('now','localtime')),
  updated_at  TEXT NOT NULL DEFAULT (datetime('now','localtime'))
);
CREATE INDEX idx_holdings_user ON holdings(user_id);
CREATE UNIQUE INDEX uq_holdings_user_code ON holdings(user_id, market, code);  -- 同用户同标的唯一
```

> 「当前持仓数量、平均成本、总投入」**不落库**，由 lots 实时聚合（见 03 文档），避免加仓/减仓后数据不一致。

## 3. lots 买入批次表（同一标的多次买入的核心）

```sql
CREATE TABLE lots (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id     INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  holding_id  INTEGER NOT NULL REFERENCES holdings(id) ON DELETE CASCADE,
  trade_date  TEXT NOT NULL,       -- 【硬】成交日期 YYYY-MM-DD（归属判定关键字段）
  direction   TEXT NOT NULL CHECK (direction IN ('buy','sell','bonus_share')),
                                   -- buy 买入 / sell 卖出 / bonus_share 送股转增（0 成本）
  shares      REAL NOT NULL CHECK (shares > 0),   -- 【硬】数量（股/份）
  price       REAL NOT NULL DEFAULT 0,            -- 【硬】成交价（单价）；送股为 0
  fee         REAL NOT NULL DEFAULT 0,            -- 【硬】交易费用（佣金/印花税等）
  note        TEXT,                -- 【硬】备注：首次建仓 / 回调加仓
  created_at  TEXT NOT NULL DEFAULT (datetime('now','localtime'))
);
CREATE INDEX idx_lots_holding ON lots(holding_id, trade_date);
CREATE INDEX idx_lots_user ON lots(user_id);
```

> 卖出批次在「可参与分红股数」聚合中按负号处理；分红归属只看 `trade_date <= 股权登记日` 的净持仓（见 03）。

## 4. dividends 分红记录表

```sql
CREATE TABLE dividends (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id       INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  holding_id    INTEGER NOT NULL REFERENCES holdings(id) ON DELETE CASCADE,
  schedule_id   INTEGER REFERENCES dividend_schedules(id),  -- 【扩】来源预案（自动匹配生成时）
  ex_date       TEXT NOT NULL,      -- 【硬】除权除息日
  record_date   TEXT,               -- 【硬】股权登记日（A股=除权日前一交易日；美股=ex_date）
  pay_date      TEXT NOT NULL,      -- 【硬】派息/到账日
  dps           REAL NOT NULL,      -- 【硬】每股/每份分红（税前，原币种，4 位小数）
  eligible_shares REAL NOT NULL,    -- 【扩】除权日参与分红的净持仓（归属计算结果）
  gross_amount  REAL NOT NULL,      -- 【硬】税前金额 = eligible_shares × dps
  tax           REAL NOT NULL DEFAULT 0,  -- 【硬】税费（自动估算，允许手工改）
  net_amount    REAL NOT NULL,      -- 【硬】税后到账 = gross - tax
  currency      TEXT NOT NULL DEFAULT 'CNY',
  div_type      TEXT NOT NULL DEFAULT 'cash' CHECK (div_type IN ('cash','bonus_share')),
  source        TEXT NOT NULL DEFAULT 'manual' CHECK (source IN ('manual','auto_schedule','imported')),
  status        TEXT NOT NULL DEFAULT 'confirmed'
                CHECK (status IN ('pending','confirmed')),   -- pending=预告待到账，confirmed=已到账
  tax_overridden INTEGER NOT NULL DEFAULT 0,  -- 【扩】税费是否被手工改过（1=是，自动重算时跳过）
  note          TEXT,
  created_at    TEXT NOT NULL DEFAULT (datetime('now','localtime')),
  updated_at    TEXT NOT NULL DEFAULT (datetime('now','localtime'))
);
CREATE INDEX idx_div_user_pay ON dividends(user_id, pay_date);
CREATE INDEX idx_div_holding ON dividends(holding_id, pay_date);
CREATE INDEX idx_div_status ON dividends(user_id, status);
CREATE INDEX idx_div_schedule ON dividends(schedule_id);
```

## 5. dividend_allocations 分红批次归属明细

> 每笔分红按批次拆分明细（原型「批次归属」展开行）。这是「同一股票多次买入」的可解释性保证。

```sql
CREATE TABLE dividend_allocations (
  id           INTEGER PRIMARY KEY AUTOINCREMENT,
  dividend_id  INTEGER NOT NULL REFERENCES dividends(id) ON DELETE CASCADE,
  lot_id       INTEGER REFERENCES lots(id) ON DELETE SET NULL,  -- 批次删除时保留快照
  lot_date     TEXT NOT NULL,       -- 批次买入日（快照，防批次改动）
  shares       REAL NOT NULL,       -- 该批次参与分红的股数
  gross        REAL NOT NULL,       -- 该批次分摊税前金额
  tax          REAL NOT NULL DEFAULT 0,   -- 该批次税费（A股按持股期限分档，见 03）
  net          REAL NOT NULL,
  note         TEXT                 -- 如「批次尚未买入，不参与」不产生行；快照说明
);
CREATE INDEX idx_alloc_div ON dividend_allocations(dividend_id);
```

## 6. dividend_schedules 分红预案表（全局公共，后台维护）

```sql
CREATE TABLE dividend_schedules (
  id           INTEGER PRIMARY KEY AUTOINCREMENT,
  market       TEXT NOT NULL CHECK (market IN ('a_share','us_stock','hk_stock','fund','bond')),
  code         TEXT NOT NULL,
  name         TEXT NOT NULL,
  ex_date      TEXT,                -- 除权除息日（未公告可空）
  record_date  TEXT,                -- 股权登记日
  pay_date     TEXT,                -- 派息日
  dps          REAL,                -- 每股分红（预案币种）
  currency     TEXT NOT NULL DEFAULT 'CNY',
  div_type     TEXT NOT NULL DEFAULT 'cash' CHECK (div_type IN ('cash','bonus_share')),
  source       TEXT NOT NULL CHECK (source IN ('crawler','manual','user_submit')),
  confidence   REAL NOT NULL DEFAULT 1.0,   -- 0~1 置信度（爬虫评分，见 03/06）
  status       TEXT NOT NULL DEFAULT 'pending'
               CHECK (status IN ('pending','published','rejected')),
  submitted_by INTEGER REFERENCES users(id),   -- user_submit 时的用户
  reviewed_by  INTEGER REFERENCES users(id),   -- 审核管理员
  reviewed_at  TEXT,
  reject_reason TEXT,
  raw_title    TEXT,                -- 公告原文标题（爬虫留痕）
  created_at   TEXT NOT NULL DEFAULT (datetime('now','localtime'))
);
CREATE INDEX idx_sch_status ON dividend_schedules(status, market);
CREATE INDEX idx_sch_code ON dividend_schedules(code, ex_date);
-- 已发布预案防重：同一标的同一除权日唯一
CREATE UNIQUE INDEX uq_sch_published ON dividend_schedules(market, code, ex_date)
  WHERE status = 'published';
```

## 7. exchange_rates 汇率表

```sql
CREATE TABLE exchange_rates (
  id           INTEGER PRIMARY KEY AUTOINCREMENT,
  base         TEXT NOT NULL,       -- USD / HKD

```

## 8. tax_rules 税率规则表（后台可配，初始化种子数据）

```sql
CREATE TABLE tax_rules (
  id           INTEGER PRIMARY KEY AUTOINCREMENT,
  market       TEXT NOT NULL,       -- a_share / us_stock / hk_stock / fund
  condition    TEXT NOT NULL,       -- 人类可读条件：「持股 > 1 年」
  rate         REAL NOT NULL,       -- 税率：0 / 0.05 / 0.10 / 0.20
  hold_min_days INTEGER,            -- 持股天数下限（A股分档用：NULL/30/365）
  hold_max_days INTEGER,
  description  TEXT,
  enabled      INTEGER NOT NULL DEFAULT 1,
  updated_at   TEXT NOT NULL DEFAULT (datetime('now','localtime'))
);
```

种子数据（对应原型后台税率表）：

| market | condition | rate | hold_min_days | hold_max_days |
|---|---|---|---|---|
| a_share | 持股 > 1 年 | 0.00 | 366 | NULL |
| a_share | 持股 1 个月 ~ 1 年 | 0.10 | 31 | 365 |
| a_share | 持股 ≤ 1 个月 | 0.20 | 0 | 30 |
| us_stock | W-8BEN 中国居民预提税 | 0.10 | NULL | NULL |
| hk_stock | 港股通内地个人 | 0.20 | NULL | NULL |
| fund | 公募基金分红免税 | 0.00 | NULL | NULL |


## 10. announcements 系统公告表

```sql
CREATE TABLE announcements (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  title       TEXT NOT NULL,
  content     TEXT NOT NULL,
  published_at TEXT,                 -- NULL=草稿

```

## 11. feedback 用户反馈表

```sql
CREATE TABLE feedback (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id     INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  content     TEXT NOT NULL,
  contact     TEXT,                  -- 联系方式（选填）
  status      TEXT NOT NULL DEFAULT 'pending'

  handled_by  INTEGER REFERENCES users(id),
  created_at  TEXT NOT NULL DEFAULT (datetime('now','localtime'))

CREATE INDEX idx_feedback_status ON feedback(status);
```

## 12. admin_operation_logs 后台操作留痕表

```sql
CREATE TABLE admin_operation_logs (
```

## 迁移约定

- schema 版本写入 `PRAGMA user_version`；每次结构变更新增 `backend/migrations/000x_xxx.sql`，启动时检查并顺序执行
- 迁 PostgreSQL 时的方言点：`datetime('now','localtime')` → `now()`；`INTEGER` 布尔 → `BOOLEAN`；AUTOINCREMENT → `GENERATED ... IDENTITY`（SQLModel 屏蔽大部分差异）
- 备份：每日 `VACUUM INTO 'backups/xi-YYYYMMDD.db'`
