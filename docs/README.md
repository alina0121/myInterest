# 息计（分红记录工具）设计文档

> 一套记录 A股 / 美股 / 港股 / 基金分红的个人投资工具，支持同一标的**多批次买入**、
> 分红按**股权登记日自动归属批次**、税后到账估算、分红预告与提醒、多用户数据隔离。
> 前端一套代码产出 Web(H5) / App / 微信小程序三端；后端 Python + SQLite 轻量部署。

## v1.1 更新摘要

- PC 独立端 `frontend-pc`（Vue3 + Vite + Element Plus，对齐原型图，含管理后台）
- 美股数据源接入 Alpha Vantage（`XI_AV_API_KEY` 环境变量，白名单 5 只）
- 批量录入/审核 API（批次/分红/预案三处，见 04 §十二）
- `scripts/seed_demo.py` 演示数据脚本（10 只股票，19 批次，22 分红，9 预案）
- 后端 `.env` 自动加载（main.py 启动时读取，无需 python-dotenv 依赖）

## 一句话技术结论

- **后端**：FastAPI + SQLModel + SQLite(WAL) + JWT，单机部署内存占用 < 80MB，可支撑千级用户
- **前端**：uni-app + Vue3 + TS + Pinia，一套代码编译 H5 / App / 微信小程序
- **后台**：P1 阶段用 sqladmin 自动生成（约 30 行配置），预案审核流做 1 个自定义页面
- **用户量上千后**：SQLite → PostgreSQL 仅改连接串，业务代码不动
